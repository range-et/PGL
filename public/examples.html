Plebeian Graph Library Examples

Examples

Large graphs in 3D, in the browser, on WebGL.

Each page is a single HTML file that imports Build/pgl_standalone.js (three.js included). Open one, then use View code to read the source. In your own project, install plebeiangraphlibrary and three from npm.

Start with example 1 API docs
Updated for 3.0.0
Edges draw as one object (one draw call), thick and thin edges are both clickable, vertex colours and opacity work, Erdős–Rényi graphs have the correct density, and Stress SGD sets up much faster. See the changelog.

Basics

Load a graph, draw nodes and edges, and change how they look.

01 Simple ZKC Zachary's karate club with precomputed positions, box nodes and thick edges. The smallest complete pipeline. Thick edges 02 Edge bundling Bundled, curved edges with vertical displacement for an arc-style flow look. DrawEdgeBundling and DisplaceEdgeInY. Bundling 03 Large point cloud 5,000-node Erdős–Rényi graph as a point cloud. All thin edges render as one LineSegments object. Scale 04 Toggle activation Recolour a random subset of point-cloud vertices with ChangeTheVertexColours and ResetVertexColors. Colour 08 ThreeWrapper variants Box nodes, simplified edges, and node/edge groups split by a node property. Styles

Layout and simulation

Live layouts that update the drawing every frame with the mutable draw calls.

09 Live 3D Kamada–Kawai 1,005-node engineering graph laid out in real time with createKamadaKawai3D (Barnes–Hut octree) and step(dt). Kamada–Kawai 12 Stress SGD live simulation Stress layout by stochastic gradient descent (s_gd2). createStressSGD3D sets up from typed arrays and stops moving once its schedule finishes. Stress SGD 13 Stress SGD 3D: Stanford bunny OBJ mesh to graph, mesh positions as the starting layout, refined in 3D so the shape stays recognisable. Stress SGDOBJ 18 Growing torus A torus mesh grows one vertex at a time while Kamada–Kawai keeps running; existing positions carry over without jumps. Dynamic graph

Algorithms and matrix math

Graph searches and linear algebra in the browser.

07 Diameter path Double BFS sweep from a random node finds a long shortest path; DrawThickPathFromNodeIds draws it. BFS 10 Adjacency matrix and power iteration get_adjacency_matrix() and matrixVectorMultiply; node size shows the leading eigenvector. Matrix 11 Custom layout from matrix math Two power-iteration vectors become X and Z coordinates through apply_position_map. MatrixLayout

Level of detail

Merge nearby nodes into super-nodes for simpler, flow-map style views.

05 Hierarchy Nodes within a distance merge into one node at their centroid; edges between groups are combined. Clustering 06 Flow map Zoom to change the clustering: fewer merged flows when zoomed out, more detail when zoomed in. ClusteringZoom
